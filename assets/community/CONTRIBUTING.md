# Contributing to {{name}}

Thank you for helping. This guide covers how to propose a change, set up the repository, and get a pull request merged.{{agents}}

## Before you start

- Search the [issues](https://github.com/{{repository}}/issues) and [pull requests](https://github.com/{{repository}}/pulls?q=is%3Apr) first, closed ones included.
- Open an issue before starting a large change or a new feature, so it can be agreed first.
- A fix for a bug or a documentation error can go straight to a pull request.
- Report a vulnerability privately as {{securityLink}} describes, not in an issue or pull request.
